🖥 모노티 홈페이지 관리 가이드

모노티 홈페이지 설정을 위한 단계별 가이드입니다.
홈페이지를 효과적으로 설정하고 관리할 수 있도록 로그인, 메뉴 설정, 테마 변경, 제품 등록, 홍보 설정 등의 기능을 안내합니다.

1. 모노티 로그인 및 대시보드 접근​

  1. 로그인 후 마이페이지로 이동

  1. 회사 관리 -> 톱니바퀴 아이콘 클릭

2. 첫 화면 설정​

✅ 설정 단계​

  1. 홈페이지 주소, 회사 이름, 사업자 번호 입력
  2. 메인 배너 사진 업로드
  3. "저장하고 다음 단계" 버튼 클릭

3. 메뉴(내비게이션) 설정​

📌 메뉴 설정 방법​

  1. 메뉴 설정으로 이동
  2. "메뉴 추가" 버튼 클릭
  3. 메뉴명 입력 + 연결할 페이지 선택
  4. 메뉴의 순서 조정 가능
  5. 저장 후 다음버튼 클릭

4. 테마 설정​

🌈 원하는 테마 선택​

  • 기본형
  • 쇼핑몰형
  • 기업형

💡 테마 선택 후 "저장하고 다음 단계" 클릭

5. 정보 등록​

🏢 회사 정보 입력​

  • 로고, 운영시간, 브레이크 타임
  • SNS(페이스북, 인스타그램), CS 번호

  • 회사 소개 작성 및 저장

🖼 포트폴리오 등록​

  1. "포트폴리오 등록" 버튼 클릭
  2. 제목, 사진, 글 업로드 후 저장

📢 공지사항 등록​

  1. "공지 등록" 버튼 클릭
  2. 공지 제목 + 내용 입력 후 저장

6. 제품 연동​

🛒 상품 등록 방법​

  1. "상품 등록" 탭에서 썸네일 이미지 & 상세 내용 입력

🔗 상품 연동​

  • "상품 연동" 탭에서 "연동하기" 버튼 클릭
  • 상품 관리 탭에서 수정 및 삭제 가능

7. 홍보 설정​

🔍 SEO 최적화 설정​

  1. 사이트 이름, 키워드, 설명 입력
  2. 보유 도메인 연결 가능
  3. "저장하고 완료" 버튼 클릭

8. 1:1 문의 답변 가이드​

📩 1:1 문의 확인 방법​

  1. 회사 관리 → 답변할 회사 선택

  1. "1:1 문의" 버튼 클릭

  1. 문의 내용 확인 후 답변 작성
